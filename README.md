# Задание: Приложение с RabbitMQ (Messaging for Inter-service communication)

## Описание задания
Данное задание демонстрирует асинхронное взаимодействие между микросервисами с использованием брокера сообщений **RabbitMQ**. 
Система состоит из двух приложений:
1. **Producer** — генерирует задачи на математические вычисления (сложение, вычитание, умножение, деление) и отправляет их в брокер раз в 3 секунды.
2. **Consumer** — получает задачи, выполняет вычисления и записывает результат в лог. Если при вычислении возникает ошибка (например, деление на ноль), сообщение отклоняется и отправляется в **Dead Letter Queue (DLQ)**.

## Архитектура
*   **Маршрутизация:** Используется `topic exchange` (`calc_exchange`) с ключами маршрутизации `calc.<operation>` (например, `calc.add`, `calc.div`).
*   **Обработка ошибок (DLQ):** Настроен Dead Letter Exchange (`calc_dlx`). Если Consumer не может обработать сообщение (ошибка деления на ноль), он вызывает `basic_nack(requeue=False)`, и сообщение попадает в очередь `calc_dlq`.
*   **Отказоустойчивость:** Сообщения публикуются с флагом `delivery_mode=2` (persistent), очереди объявлены как `durable`.
